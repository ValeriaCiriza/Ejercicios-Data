# Ejercicios de análisis de datos con Python

Ejercicios del curso Empleo Data + IA (Career Tech Hub), ordenados por temas. Valeria Ciriza · 2026.

Los proyectos completos están en sus propios repositorios:
- [Lead Scoring](https://github.com/ValeriaCiriza/proyecto-m1): a qué contactos llamar primero (pandas + Streamlit).
- [Bar La Consulta a domicilio](https://github.com/ValeriaCiriza/bar-la-consulta-domicilio): si al bar le compensa repartir (SQL + pandas + Streamlit).

## Contenido

| Carpeta | Qué se practica |
|---|---|
| `01-introduccion` | Primeros pasos con datos |
| `02-python-basico` | Variables, listas, bucles y funciones en Python |
| `03-numpy-pandas` | Tablas con pandas: filtrar, agrupar y ordenar |
| `04-graficos-y-eda` | Gráficos y análisis exploratorio (Titanic, hoteles, Airbnb Madrid) |
| `05-apis` | Traer datos de APIs con `requests` (Star Wars, el tiempo en Madrid) |
| `06-social-media` | Análisis de datos de redes sociales |
| `07-fast-food` | Análisis de datos de comida rápida |
| `08-sql-bar` | Consultas SQL con la base de datos del bar La Consulta |
| `09-streamlit` | Primeras apps con Streamlit |

## Cómo abrirlos

```
pip install pandas matplotlib requests streamlit
```

Abre cada cuaderno (`.ipynb`) con VS Code o Jupyter. Los CSV que usa cada uno están en su misma carpeta.
